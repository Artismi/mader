SEZIONE 1 — TIPI DI ELEMENTI (type)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Ogni elemento nel board JSON ha queste proprietà di base:
  type       → (obbligatorio) uno dei tipi qui sotto
  x, y       → posizione top-left in pixel (0 = angolo top-left del canvas)
  w, h       → larghezza e altezza in pixel
  angle      → rotazione in gradi (-180 a 180), default 0
  opacity    → 0.0–1.0, default 1.0
  effects    → array di stringhe (vedi Sezione 3), default []
  effectProps→ oggetto con parametri per ogni effetto (vedi Sezione 3)

TIPI DISPONIBILI:

──────────────────────────────────────
"rect"
  Rettangolo riempito. Il tipo più versatile — sfondi, blocchi, barre, divisori.
  Proprietà extra:
    fill        → colore OKLCH, hex, rgba, o gradient object
    stroke      → colore bordo (stringa colore)
    strokeWidth → spessore bordo in pixel (0 = nessun bordo)
    borderRadius→ raggio angoli in pixel (0 = angoli vivi)

──────────────────────────────────────
"circle"
  Ellisse/cerchio. Usa w e h per controllare proporzioni.
  Proprietà extra:
    fill, stroke, strokeWidth (come rect)

──────────────────────────────────────
"triangle"
  Triangolo equilatero.
  Proprietà extra:
    fill, stroke, strokeWidth

──────────────────────────────────────
"text"
  Testo statico. Usare per headline, body, annotazioni, label.
  Proprietà extra:
    text         → stringa contenuto (obbligatorio)
    fontFamily   → nome font (vedi Sezione 6 — FONT)
    fontSize     → dimensione in px (default 24)
    fontWeight   → "100"|"200"|"300"|"400"|"500"|"600"|"700"|"800"|"900"|"bold"|"normal"
    fontStyle    → "normal"|"italic"
    textAlign    → "left"|"center"|"right"|"justify"
    fill         → colore del testo
    letterSpacing→ tracking in px (0 = normale; positivo = dilata; negativo = comprime)
    lineHeight   → interlinea come moltiplicatore (1.2 = normale, 1.8 = ampia)
    textTransform→ "none"|"uppercase"|"lowercase" (applicato visivamente)
    underline    → boolean
    stroke       → colore contorno testo
    strokeWidth  → spessore contorno testo in pixel

──────────────────────────────────────
"image"
  Immagine da URL o asset cliente.
  Proprietà extra:
    src           → URL immagine (usare asset del cliente da list_client_assets)
    removeBackground → boolean — se true, rimuove bg prima di applicare
    cropX, cropY  → offset ritaglio (0–1)
    cropW, cropH  → dimensione ritaglio (0–1)

──────────────────────────────────────
"path"
  Forma SVG custom da path string. Per forme dalla shape library o path disegnati.
  Proprietà extra:
    path         → stringa SVG path (vedi Sezione 7 — FORME)
    fill, stroke, strokeWidth

──────────────────────────────────────
"line"
  Linea retta da punto A a punto B.
  Proprietà extra:
    x2, y2       → endpoint della linea (x,y sono l'endpoint iniziale)
    stroke       → colore linea
    strokeWidth  → spessore in pixel
    strokeDashArray → array per linee tratteggiate [lunghezza, spazio], es. [10, 5]

──────────────────────────────────────
"procedural"
  Pattern generativo algoritmico. Crea texture di sfondo e pattern ripetuti.
  Proprietà extra:
    proceduralType → tipo del pattern (vedi Sezione 5 — PROCEDURALI)
    color          → colore del pattern
    density        → densità 0.1–1.0
    radius         → dimensione unità base
    spacing        → spaziatura tra elementi (per tipi che lo supportano)
    amplitude      → ampiezza ondulazione (per wave_lines, zigzag)
    angle          → angolo del pattern in gradi (per stripe_diagonal)
    weight         → spessore linea (per tipi line-based)

──────────────────────────────────────
"group"
  Raggruppa più elementi. Usato internamente — preferire elementi singoli nel JSON.

──────────────────────────────────────
"textbox"
  Testo multiriga con word-wrap automatico. Per paragrafi di testo lungo.
  Proprietà extra: tutte quelle di "text" +
    width → larghezza fissa del box (il testo va a capo automaticamente)

SEZIONE 2 — SISTEMA COLORE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

FORMATO PREFERITO: OKLCH
  Usare SEMPRE OKLCH per i colori nella palette del design. È perceptually uniform —
  i salti di L si percepiscono come uguali su tutta la gamma cromatica.

  Sintassi: "oklch(L C H)"
    L = lightness 0–1   (0 = nero, 1 = bianco)
    C = chroma 0–0.4    (0 = grigio, 0.4 = massima saturazione)
    H = hue 0–360       (0/360=rosso, 120=verde, 240=blu, 300=viola)

  Esempi pratici:
    "oklch(0.97 0.015 70)"   → bianco-crema caldo (sfondo carta)
    "oklch(0.14 0.03 250)"   → quasi-nero blu (inchiostro)
    "oklch(0.50 0.28 260)"   → blu elettrico saturo
    "oklch(0.55 0.28 25)"    → rosso vermiglio
    "oklch(0.70 0.22 140)"   → verde acido
    "oklch(0.65 0.30 300)"   → magenta pop
    "oklch(0.82 0.18 90)"    → giallo caldo
    "oklch(0.18 0.02 0)"     → grigio scuro neutro

FORMATI ALTERNATIVI SUPPORTATI:
  "#rrggbb"   → hex standard
  "rgba(r,g,b,a)" → rgba con alpha
  "transparent"   → trasparente (per sfondi)

GRADIENTE (fill con oggetto gradient):
  {
    "type": "linear",
    "coords": { "x1": 0, "y1": 0, "x2": 1, "y2": 0 },
    "colorStops": [
      { "offset": 0, "color": "oklch(0.55 0.30 260)" },
      { "offset": 1, "color": "oklch(0.55 0.30 300)" }
    ]
  }

  Per gradiente radiale:
  {
    "type": "radial",
    "coords": { "x1": 0.5, "y1": 0.5, "r1": 0, "x2": 0.5, "y2": 0.5, "r2": 0.5 },
    "colorStops": [
      { "offset": 0, "color": "oklch(0.60 0.25 260)" },
      { "offset": 1, "color": "oklch(0.20 0.05 260)" }
    ]
  }

  Direzioni lineare comuni (coords da 0 a 1 = relativo all'oggetto):
    Orizzontale sx→dx:  { "x1": 0, "y1": 0, "x2": 1, "y2": 0 }
    Verticale top→bot:  { "x1": 0, "y1": 0, "x2": 0, "y2": 1 }
    Diagonale:          { "x1": 0, "y1": 0, "x2": 1, "y2": 1 }

SEZIONE 3 — EFFETTI CUSTOM (effects array)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Gli effetti vengono applicati tramite:
  "effects": ["nome_effetto"],
  "effectProps": { "nome_effetto": { "parametro": valore } }

Gli effetti si SOMMANO — puoi combinare più effetti sulla stessa tavola.
Ordine consigliato: effetti stilistici prima, animati dopo.

━━━ EFFETTI DI STILE (non animati) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"3d"
  Effetto tridimensionalità volumetrica con ombra prospettica.
  Params: depth (5–30, default 10), angle (0–360, default 45), color (hex)
  Uso: elementi hero, testo display, forme architettoniche
  Esempio: "effectProps": { "3d": { "depth": 15, "angle": 45 } }

"glass"
  Effetto vetro/glassmorphism — sfondo semi-trasparente con bordo luminoso.
  Params: opacity (1–30, default 10), border (1–30), color (hex, default "#ffffff")
  Uso: card overlay, panel premium, UI moderna
  Esempio: "effectProps": { "glass": { "opacity": 15, "border": 8 } }

"clay"
  Effetto plastilina/3D morbido — volume gonfiato con ombra morbida.
  Params: softness (10–60, default 30), volume (20–80, default 50),
          gloss (10–60, default 30), matte (0–40, default 20), color (hex)
  Uso: UI friendly, stile kawaii, brand giocoso
  Esempio: "effectProps": { "clay": { "softness": 35, "volume": 60, "gloss": 40 } }

"riso"
  Effetto risograph — duplicazione cromatica con offset colori (print aesthetic).
  Params: color1 (hex, default #f72585), color2 (hex, default #4cc9f0),
          intensity (10–100, default 50)
  Uso: poster indipendente, zine aesthetic, stampa artigianale
  Esempio: "effectProps": { "riso": { "color1": "#ff6b00", "color2": "#0055ff", "intensity": 60 } }

"thermal"
  Effetto termocamera — rimappa i colori su scala termica (rosso-giallo-blu).
  Params: intensity (50–100, default 100), shift (0–100, default 0)
  Uso: surveillance aesthetic, tech-distopian, visualizzazioni dati
  Esempio: "effectProps": { "thermal": { "intensity": 90 } }

"bloom"
  Bagliore luminoso intorno alle zone chiare — effetto cinema dreamy.
  Params: threshold (20–80, default 55), intensity (20–80, default 50),
          radius (10–80, default 50)
  Uso: vaporwave, dreamcore, luci notturne, atmosfera onirica
  Esempio: "effectProps": { "bloom": { "threshold": 40, "intensity": 60, "radius": 30 } }

"outline"
  Contorno netto di colore solido intorno all'oggetto.
  Params: thickness (1–50, default 20), color (hex, default "#ffffff")
  Uso: pop art, fumetto, street art, separazione elementi
  Esempio: "effectProps": { "outline": { "thickness": 30, "color": "#000000" } }

"prism"
  Aberrazione cromatica prismatica — spostamento RGB come vetro difrangente.
  Params: amount (5–50, default 20)
  Uso: vaporwave, glam, Y2K, effetto lente ottica vintage
  Esempio: "effectProps": { "prism": { "amount": 25 } }

"halftone"
  Pattern a punti retinati come stampa tipografica vintage.
  Params: size (4–20, default 10), intensity (30–80, default 50)
  Uso: pop art, risograph, editorial vintage, stampa artigianale
  Esempio: "effectProps": { "halftone": { "size": 8, "intensity": 60 } }

"pixelate"
  Pixelazione — riduce la risoluzione visiva in blocchi quadrati.
  Params: size (4–24, default 8)
  Uso: pixel art, 8-bit, censura artistica, glitch
  Esempio: "effectProps": { "pixelate": { "size": 12 } }

"oil"
  Pittura a olio — smeared texture organica.
  Params: radius (20–80, default 50), intensity (50–100, default 80)
  Uso: arte classica, texture pittorica, editorial lusso
  Esempio: "effectProps": { "oil": { "radius": 40, "intensity": 85 } }

"skew"
  Deformazione prospettica — inclina l'oggetto orizzontalmente o verticalmente.
  Params: x (gradi skew X, default 10), y (gradi skew Y, default 0)
  Uso: headline dinamiche, poster sport, effetti di moto
  Esempio: "effectProps": { "skew": { "x": 15, "y": 0 } }

━━━ EFFETTI ANIMATI (RAF — si muovono in loop automatico) ━━━━━━━━━━━━━━━━━━━━

IMPORTANTE: gli effetti animati si aggiornano a ogni frame. Usare con parsimonia
(max 2-3 su tutto il canvas) per non sovraccaricare il rendering.

"glitch"
  Glitch digitale — spostamento RGB con scan lines intermittenti.
  Params: amount (5–30, default 10)
  Uso: hacker, cyber, distopico, lo-fi tech
  Esempio: "effectProps": { "glitch": { "amount": 15 } }
  ANIMATO: disturbo si muove in loop

"wavy"
  Distorsione sinusoidale ondulante.
  Params: intensity (20–80, default 50), frequency (5–20, default 10)
  Uso: psichedelico, liquido, acqua, organic digital
  Esempio: "effectProps": { "wavy": { "intensity": 40, "frequency": 8 } }
  ANIMATO: onda in moto continuo

"liquid"
  Fluido lava lamp — distorsione liquida lenta.
  Params: intensity (30–70, default 50), scale (15–50, default 30)
  Uso: organic, sensuale, brand fluid, vaporwave soft
  Esempio: "effectProps": { "liquid": { "intensity": 55, "scale": 25 } }
  ANIMATO: movimento fluido perpetuo

"vhs"

  Uso: Y2K, nostalgia '90s, lo-fi, found footage

  ANIMATO: noise si aggiorna continuamente

"matrix"
  Pioggia di codice verde — effetto Matrix/hacker.
  Params: intensity (50–90, default 70)
  Uso: cyber, hacker, tech noir, terminal aesthetic
  Esempio: "effectProps": { "matrix": { "intensity": 75 } }

"chrome"  [ALIAS: LiquidMetalFilter]
  Superficie metallica liquida — riflessi cromati in movimento.
  Params: intensity (30–70, default 50)
  Uso: Y2K, chrome, lusso metallico, car aesthetic
  Esempio: "effectProps": { "chrome": { "intensity": 60 } }
  ANIMATO: riflessi in movimento

"holo"
  Effetto olografico — variazione iridescente di colori come carta olografica.
  Params: intensity (30–70, default 50), speed (20–80, default 50)
  Uso: Y2K, crypto, premium tech, carte collezionabili
  Esempio: "effectProps": { "holo": { "intensity": 55, "speed": 40 } }
  ANIMATO: colori mutano in loop

"neon"
  Bagliore neon — testo/forma che brilla come tubo al neon.
  Params: color (hex), blur (10–60, default 30), intensity (3–10, default 5)
  Uso: nightlife, cyberpunk, insegna luminosa, darkmode
  Esempio: "effectProps": { "neon": { "color": "#ff00ff", "blur": 40, "intensity": 6 } }
  ANIMATO: pulsazione lenta

"grain"
  Grana pellicola — rumore analogico come film 35mm.
  Params: (nessuno — intensità built-in)
  Uso: fotografia analogica, editorial, nostalgia
  ANIMATO: grain si aggiorna a ogni frame

━━━ EFFETTI STILE AVANZATO (appena cablati v2) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"duotone"
  Color grading 3-way professionale — shadows/midtones/highlights su tre colori separati.
  Params: shadow ([R,G,B] default [0,10,60]), mid ([R,G,B] default [120,150,180]),
          highlight ([R,G,B] default [255,230,200]), contrast (50–150, default 100),
          intensity (50–100, default 100)
  Uso: poster fotografico, editorial B&W colorizzato, moodboard
  Esempio: "effectProps": { "duotone": { "shadow": [10,0,50], "highlight": [255,220,180], "contrast": 110 } }

"vignette"
  Vignettatura fotografica con aberrazione cromatica radiale.
  Params: strength (30–90, default 70), radius (20–80, default 50),
          aberration (0–60, default 30), saturation (30–80, default 60)
  Uso: fotografia analogica, portrait premium, editorial atmosferico
  Esempio: "effectProps": { "vignette": { "strength": 60, "radius": 45 } }

"posterize"
  Posterizzazione — riduce i livelli di colore come serigrafia silk-screen.
  Params: steps (2–8, default 4), dither (20–80, default 50), vibrance (20–60, default 40)
  Uso: pop art, stampa serigrafica, poster artistico
  Esempio: "effectProps": { "posterize": { "steps": 3, "dither": 60, "vibrance": 50 } }

"ascii"
  ASCII art — converte pixel in caratteri di densità (effetto terminale).
  Params: size (4–16, default 8), intensity (50–100, default 100)
  Uso: cyber, hacker terminal, retro computing, glitch art
  Esempio: "effectProps": { "ascii": { "size": 6, "intensity": 90 } }

"fiber"
  Texture carta/fibra — grana anisotropica come carta handmade o cartone.
  Params: intensity (20–60, default 40), roughness (30–70, default 50), scale (50–150, default 100)
  Uso: carta artigianale, packaging premium, mincho washi texture
  Esempio: "effectProps": { "fiber": { "intensity": 35, "roughness": 60 } }

━━━ FILTRI STANDARD FABRIC.JS (usare per immagini e aggiustamenti) ━━━━━━━━━━━

"Brightness"
  Params: value (-100 a 100, default 0)

"Contrast"
  Params: value (-100 a 100, default 0)

"Saturation"
  Params: value (-100 a 100, default 0)

"Blur"
  Params: value (0 a 100, default 0) — 100 = blur massimo

"Noise"
  Params: value (0 a 100, default 0) — aggiunge grana random

"HueRotation"
  Params: value (0 a 360, default 0) — ruota hue in gradi

"Grayscale"
  Params: nessuno — converte in bianco e nero

"Sepia"
  Params: nessuno — tono seppia vintage

"Invert"
  Params: nessuno — inverte tutti i colori

SEZIONE 4 — COMBINAZIONI EFFETTI RACCOMANDATE PER MOVIMENTO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ANTI-GRAVITY MINIMAL:
  → Nessun effetto custom. Solo Brightness/Contrast leggeri sulle immagini.
  → Al massimo: 1 elemento con "bloom" a intensità bassa (20)

DIGITAL BRUTALISM:
  → "glitch" su elementi headline (amount 10–15)
  → "outline" su forme primarie (color: "#000000", thickness 20–30)
  → "vhs" su immagini background (intensity 40)

VAPORWAVE:
  → "holo" su elementi hero (intensity 60)
  → "bloom" su tutto (threshold 35, intensity 50)
  → "prism" su testo display (amount 15–20)
  → "chrome" su elementi metallici

Y2K / ACID GRAPHICS:
  → "chrome" su forme primarie
  → "prism" su testo (amount 20–30)
  → "holo" su elementi secondari

SWISS MINIMAL:
  → Nessun effetto. Purezza tipografica totale.

ART NOUVEAU:
  → "oil" su elementi decorativi (radius 30, intensity 70)
  → "bloom" su elementi floreali (threshold 50, intensity 30)

POP ART:
  → "halftone" su immagini (size 8, intensity 65)
  → "outline" su oggetti (color: "#000000", thickness 25)

CONSTRUCTIVISM:
  → "3d" su forme geometriche (depth 12, angle 315)
  → "outline" su testo (color: "#000000", thickness 15)

GLITCH / HACKER:
  → "glitch" su testo headline (amount 15–20)
  → "matrix" su background rect (intensity 70)
  → "vhs" su immagini (intensity 60)
  → "pixelate" su zone specifiche (size 8–12)

MINCHO × HANDWRITTEN:
  → Nessun effetto su tipografia
  → "fiber" su sfondo carta (intensity 30, roughness 65) — simula washi texture
  → Solo "grain" come alternativa

WATERCOLOR EDITORIAL:
  → "oil" su wash di colore (radius 25, intensity 65)
  → "Blur" su bordi dei wash (value 15–25)
  → "vignette" su immagini (strength 40, radius 60)

FUMETTO / MANGA:
  → "halftone" su figure (size 6, intensity 55)
  → "outline" su personaggi (color "#000000", thickness 25)
  → "posterize" su zone di colore (steps 3, vibrance 50)

STUDIO PREMIUM (Apple-style):
  → "vignette" su immagini prodotto (strength 30, radius 70, aberration 15)
  → "Brightness" +5, "Contrast" +8 su immagini

DUOTONE USE CASES (qualsiasi movimento):
  → "duotone" trasforma qualsiasi immagine in bicromia di movimento
  → Swiss: shadow [20,20,20], highlight [240,240,240]
  → Luxury: shadow [10,0,40], highlight [255,240,210]
  → Surveillance: shadow [0,30,0], highlight [180,255,180]
  → Vaporwave: shadow [40,0,80], highlight [255,180,255]

LUXURY FASHION:
  → "chrome" su elementi metallici
  → "bloom" su oggetti hero (threshold 60, intensity 25)

PIXEL RETRO 8-BIT:
  → "pixelate" su immagini (size 8–16)
  → Nessun altro effetto — la flat-ness è assoluta

  → "riso" su forme colorate (intensity 40–60)

SEZIONE 5 — PATTERN PROCEDURALI (proceduralType)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

I pattern procedurali creano texture algoritmiche come sfondi o overlay.
Usare type: "procedural" con le proprietà:
  proceduralType → stringa tipo (obbligatorio)
  color          → colore degli elementi del pattern
  density        → 0.1–1.0 (quanto è denso il pattern)
  radius         → dimensione base degli elementi
  opacity        → 0.0–1.0 sull'intero gruppo
  w, h           → dimensioni dello strato procedural (di solito = dimensioni canvas)

TIPI DISPONIBILI:

"halftone"
  Griglia di cerchi di dimensione variabile — simula retino tipografico.
  Effetto: cerchi più grandi nelle zone di picco sinusoidale.
  Best for: pop art, editorial vintage, risograph aesthetic
  Params consigliati: density 0.4–0.7, radius 4–8

"dot_grid"
  Griglia ortogonale di punti uguali — carta millimetrata da laboratorio.
  Effetto: punti uniformi a spaziatura regolare.
  Best for: tech blueprint, pixel retro, grid paper aesthetic
  Params consigliati: density 0.3–0.6, radius 2–4

"wave_lines"
  Linee orizzontali ondulate — topografia o segnale audio.
  Effetto: linee continue con ondulazione sinusoidale sovrapposta.
  Best for: psichedelico, organic, topographic map, vaporwave
  Params consigliati: density 0.4–0.8, radius 3–6

"zigzag_fill"  [NUOVO v2]
  Riempimento a zig-zag — pattern angolare alternato.
  Effetto: linee spezzate diagonali che riempiono la superficie.
  Best for: sport energy, constructivism, brutalist pattern
  Params consigliati: density 0.4–0.7, amplitude 20–40

"stripe_diagonal"  [NUOVO v2]
  Strisce diagonali uniformi — barberpole o awning.
  Effetto: bande parallele a angolo fisso.
  Best for: sport, fashion, editorial, pop art
  Params consigliati: density 0.3–0.6, angle 45 (default), weight 2–8

"star_scatter"  [NUOVO v2]

  Effetto: stelle a 4-6 punte di dimensioni variabili distribuite random.
  Best for: memphis, vaporwave, kawaii, celebrativo
  Params consigliati: density 0.2–0.5, radius 4–12

"crosshatch"  [NUOVO v2]

  Effetto: griglia di linee diagonali incrociate (hatching).

"honeycomb"  [NUOVO v2]

SEZIONE 8 — PROPRIETÀ CANVAS E COMPOSIZIONE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DIMENSIONI STANDARD DEL CANVAS:
  800 × 600 px  — landscape standard (default)
  600 × 800 px  — portrait (poster, mobile)
  800 × 800 px  — square (social, instagram)
  1200 × 630 px — OG banner (social sharing)

L'origine (0,0) è l'angolo TOP-LEFT del canvas.
x aumenta verso destra, y aumenta verso il basso.

REGOLA DI LAYERING (z-order):
  Gli elementi nel JSON array sono renderizzati dal PRIMO (bottom) all'ULTIMO (top).
  Quindi: sfondo (index 0) → layers intermedi → elementi in primo piano (index n).

  Struttura tipica:
    [0] → rect sfondo (colore base o gradiente)
    [1] → procedural pattern overlay (opacity 0.2–0.5)
    [2..n-3] → elementi compositivi principali
    [n-2] → testo headline/display
    [n-1] → micro-testo, firma, data

NEGATIVE SPACE:
  Lasciare sempre il % di spazio vuoto indicato dalla ricetta del movimento.
  NON riempire tutto il canvas. Il vuoto è un elemento compositivo.

COORDINATE SICURE:
  Ogni elemento deve stare DENTRO i confini del canvas.
  x: 0 a (canvas_width - element_width)
  y: 0 a (canvas_height - element_height)

ANGOLAZIONI:
  Usare angoli leggeri per annotazioni e elementi secondari: -8° a +8°
  Per effetti di impatto: -15° a +15°
  Non usare angoli > 45° salvo design estremamente specifici

OPACITÀ:
  Sfondi procedurali overlay: 0.1–0.4
  Elementi decorativi secondari: 0.3–0.7
  Elementi principali: 0.85–1.0
  Texture carta/grain overlay: 0.03–0.08
