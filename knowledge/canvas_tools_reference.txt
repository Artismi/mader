## Canvas Tools Reference — Creative OS
Questa è la documentazione completa degli strumenti disponibili nel canvas Fabric.js.
Il Canvas Board Generator DEVE usare queste risorse invece di limitarsi a rect+text+image.

---

## 1. ELEMENT TYPES

### type: "rect"
Rettangolo base. Supporta tutti gli effects.
```json
{"type":"rect","x":0,"y":0,"w":540,"h":1080,"color":"#1a1a2e","opacity":1,"zIndex":0,"borderRadius":0,
 "stroke":"#ffffff","strokeWidth":0,"gradient":{"type":"linear","angle":135,"stops":[{"offset":0,"color":"#1a1a2e"},{"offset":1,"color":"#0d0d1a"}]}}
```

### type: "text"
Testo editabile. fontFamily deve essere un font Google Fonts valido.
```json
{"type":"text","x":50,"y":150,"w":440,"h":300,"text":"HEADLINE REALE","fontFamily":"Bebas Neue",
 "fontSize":140,"fontWeight":"900","letterSpacing":-0.02,"lineHeight":0.95,
 "textTransform":"uppercase","textAlign":"left","color":"#ffffff","zIndex":9}
```

### type: "image"
Immagine da URL. Preferire proxy `/api/proxy-image?url=...` per URL esterni.
```json
{"type":"image","x":540,"y":0,"w":540,"h":700,"url":"https://...","zIndex":4,"opacity":1}
```

### type: "line"
Linea/divisore decorativo. Usa x1,y1,x2,y2.
```json
{"type":"line","x":0,"y":0,"w":0,"h":0,"x1":0,"y1":540,"x2":1080,"y2":540,
 "stroke":"#e63946","strokeWidth":2,"opacity":0.6,"zIndex":2}
```

### type: "procedural" ← USALO PER TEXTURE DI SFONDO
Pattern generativo che crea texture uniche. NON è un'immagine.
```json
{"type":"procedural","proceduralType":"halftone","x":0,"y":0,"w":1080,"h":1080,
 "color":"#ffffff","opacity":0.08,"density":0.4,"procRadius":4,"zIndex":1}
```
**proceduralType disponibili:**
- `"halftone"` — cerchi variabili a onde sinusoidali. Effetto pop-art/tipografia.
- `"dot_grid"` — griglia precisa di punti equidistanti. Effetto blueprint/tech.
- `"wave_lines"` — linee topografiche ondulate. Effetto contour map/organic.

## 2. EFFECTS — Lista completa

Applica con: `"effects": ["neon"]` e opzionalmente `"effectProps": {"color":"#00ffff","blur":40}`

### MOTION (animati — visibili in preview)
| Key | Effetto visivo | effectProps chiave |
|-----|----------------|--------------------|
| `"glitch"` | Aberrazione cromatica, shift RGB | `amount` (0-100) |
| `"wavy"` | Onda liquida ripple | `intensity`,`frequency` |
| `"liquid"` | Flusso liquido organico | `intensity` |
| `"vhs"` | Scanlines VHS, rumore analogico | `intensity` |
| `"matrix"` | Digital rain verde | `intensity` |
| `"chrome"` | Chrome metallico fluido | `intensity` |
| `"holo"` | Shimmer olografico arcobaleno | `intensity`,`speed` |

### OPTICAL (luce, lenti)
| Key | Effetto visivo | effectProps chiave |
|-----|----------------|--------------------|
| `"neon"` | Alone neon colorato, glow | `color`(hex),`blur`,`intensity` |
| `"bloom"` | Luce morbida, photographic flare | `threshold`,`intensity`,`radius` |
| `"thermal"` | Mappa termica infrarossi | `intensity`,`shift` |

### TEXTURE (superficie)
| Key | Effetto visivo | effectProps chiave |
|-----|----------------|--------------------|
| `"grain"` | Grano cinematografico, pellicola | `intensity` |
| `"halftone"` | Punti mezzatinta, stampa offset | `size`,`angle` |

### STYLE (artistico)
| Key | Effetto visivo | effectProps chiave |
|-----|----------------|--------------------|
| `"3d"` | Estrusione volumetrica 3D | `depth`,`angle`,`color` |
| `"glass"` | Vetro frosted, UI glassmorphism | `opacity`,`color`,`border` |
| `"clay"` | Plastica clay morbida, materica | `volume`,`gloss`,`matte`,`softness` |
| `"riso"` | Stampa risograph duotone | `color1`,`color2`,`intensity` |
| `"outline"` | Contorno/stroke premium | `color`,`thickness` |
| `"skew"` | Prospettiva/inclinazione | `x`,`y` |

### Combinazioni raccomandate per mood:
- **luxury**: `["grain"]` su foto + `["3d"]` su titolo
- **tech/cyber**: `["neon"]` su linee + `["glitch"]` su immagini + `["matrix"]` BG
- **editorial**: `["halftone"]` su foto + grano leggero su BG
- **brutalist**: `["riso"]` + `["skew"]` sul titolo principale
- **fashion**: `["grain"]` intenso + `["bloom"]` su foto
- **retro/70s**: `["riso"]` + grain pesante
- **glassmorphism/UI**: `["glass"]` su card + blur BG

## 5. GRADIENTS

```json
"gradient": {
  "type": "linear",
  "angle": 135,
  "stops": [
    {"offset": 0, "color": "#0d0d1a"},
    {"offset": 0.5, "color": "#1a0a2e"},
    {"offset": 1, "color": "#000000"}
  ]
}
```
- `type: "radial"` per gradienti circolari
- Angoli comuni: 0=vert top-bottom, 90=orizz, 135=diag, 45=diag inv

## 7. REGOLE CONTESTUALI PER EFFETTI

- **Su foto lifestyle**: prefer `bloom` + `grain` — morbidezza cinematografica
- **Su foto prodotto**: `grain` leggero + `outline` per staccare dal BG
- **Su headline dominante**: `3d` o `neon` (no entrambi)
- **Su BG rect scuro**: `procedural` + `grain` per evitare flat look
- **Su elementi tech**: `neon` + `matrix` o `glitch`
- **Mai**: grain + riso + glitch sullo stesso oggetto (overloading)
- **Mai**: effetti animati (liquid,wavy,vhs,matrix,holo) su tutti gli elementi contemporaneamente

  "neon":     {"color": "#hex", "blur": 10-80, "intensity": 1-20},
  "glitch":   {"amount": 5-50},

  "bloom":    {"threshold": 40-80, "intensity": 0.1-1.0, "radius": 3-15},
  "riso":     {"color1": "#hex", "color2": "#hex", "intensity": 30-80},
  "wavy":     {"intensity": 20-80, "frequency": 5-20},

  "holo":     {"intensity": 30-80, "speed": 20-80},
  "halftone": {"size": 3-12, "angle": 0-90},
